# 🐍 Snake Game en C++

Recreación del clásico juego de la serpiente (**Snake Game**) desarrollado en **C++** para ejecutarse desde la consola de comandos.

---

## 🚀 Características

- 🎮 **Mecánica Clásica:** Controla la serpiente para comer alimentos, aumentar de tamaño y sumar puntos.
- 🕹️ **Controles por Teclado:** Movimiento fluido a través de las teclas de dirección o conjunto WASD.
- 💀 **Detección de Colisiones:** Fin del juego al chocar con los bordes del mapa o con el propio cuerpo de la serpiente.
- 📊 **Marcador de Puntuación:** Registro dinámico de la puntuación obtenida durante la partida.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** C++ (C++11 o superior)
- **Librerías Estándar / Consola:** `<iostream>`, `<conio.h>` / `<windows.h>` (según la plataforma de ejecución)
- **Entorno Recomendado:** Visual Studio, Code::Blocks, Dev-C++ o VS Code
